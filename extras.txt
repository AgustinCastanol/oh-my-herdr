# oh-my-herdr curated extras
#
# Third-party herdr plugins that install.sh installs only with --with-extras.
# They are not sandboxed: a plugin runs with your user's permissions. Each one
# was reviewed at the commit pinned here and is installed from exactly that
# commit with: herdr plugin install <source> --ref <ref> --yes
#
# Format: one plugin per line, fields separated by spaces or tabs.
#
#   source       GitHub owner/repo, optionally /subdir, as `herdr plugin
#                install` takes it
#   ref          the full 40-character commit to install
#   id           the plugin id from its herdr-plugin.toml; used to uninstall
#   requires     commands it needs on PATH, separated by commas; a|b means
#                any one of a or b; - means none
#   description  the rest of the line
#
# Lines starting with # and blank lines are ignored. See "Extras" in
# README.md for what each plugin does and the security notes.
